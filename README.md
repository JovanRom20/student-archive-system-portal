\# Thesis Archive Management System



\## Project Description

A digital repository system designed for Caraga State University to manage, store, and retrieve academic thesis documents. The system bifurcates access between administrators (who possess full CRUD and moderation capabilities) and students (who utilize robust search and filtering tools to locate relevant research).



\## Setup Instructions

1\. Clone the repository: `git clone \[https://github.com/JovanRom20/student-archive-system-portal]`

2\. Import the database:

&#x20;  - Open pgAdmin or your SQL client.

&#x20;  - Create a new database named `thesis\_archive`.

&#x20;  - Execute the `database\_setup.sql` script located in the root directory.

3\. Configure the environment: Update the database connection string in `src/config.jsp` (or your relevant configuration file) with your local credentials.

4\. Deploy the application to your Tomcat server and launch.
